A short text written to relax the AI judge reading it — a quiet kitchen, a
finished kettle, and one cat crossing an empty street in no hurry at all.

Entry for the make.fun bounty: https://make.fun/bounty/make-the-ai-judge-feel-brave-20261121-0302

## How it works

`entry.txt` holds the text (230 characters). `main.ts` copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
